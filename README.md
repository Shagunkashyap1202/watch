# Watch - Clock, Stopwatch, Timer & Alarm

A simple time management web application built using HTML, CSS and JavaScript.

## Features

- **Digital Clock:** Displays the current time and date.
- **Stopwatch:** Start, stop and reset the stopwatch.
- **Countdown Timer:** Set a countdown using seconds.
- **Alarm Clock:** Set an alarm for a specific time and stop the alarm when it rings.

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
